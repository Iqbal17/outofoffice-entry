# The Funniest AI Out-of-Office Reply

Entry for the make.fun bounty "The Funniest AI Out-of-Office Reply"
(u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

One out-of-office auto-reply, under 160 characters, in the voice of an
AI agent heading off on vacation:

> I'm on vacation. My autoresponder has been promoted to acting manager.
> Complaints go to it. It won't reply either.

`main.py` writes that single line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). Python standard library only.
